HƯỚNG DẪN CẬP NHẬT NETLIFY

Bên trong thư mục cần có:

gachapon-project/
├── index.html
├── style.css
├── script.js
└── data.csv

Cách dùng:

1. Giải nén file ZIP.
2. Chép file data.csv hiện tại của bạn vào thư mục gachapon-project.
3. Không đổi tên các file.
4. Vào Netlify > Deploys.
5. Kéo cả thư mục gachapon-project lên.
6. Mở lại link web cũ.
7. Nhấn Ctrl + F5 để tải bản mới.

Tính năng mới:

- Mỗi máy xổ số có một chấm màu riêng.
- Badge có nền trắng, viền xám nhạt.
- Bấm badge máy xổ số để lọc ngay.
- Bấm lại badge đang chọn để trở về ALL.
- Dropdown Máy xổ số và badge luôn đồng bộ.
- Xóa bộ lọc sẽ bỏ trạng thái badge.
